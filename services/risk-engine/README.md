# services/risk-engine — Risk Scoring

Responsibility: score events and situations for risk using interpretable rules
and learned models, producing an explainable risk score with supporting evidence
(who, what, when, where, why, confidence) for the human-review dashboard.

Every high-risk alert must be explainable — the engine never autonomously
accuses; it surfaces evidence for human review.
